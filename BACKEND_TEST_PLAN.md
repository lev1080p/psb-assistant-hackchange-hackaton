# План проверки backend ПСБ

## Исходное состояние и источники

База этой работы — опубликованный коммит `88527a38981125b6e493ff8633879ffcc7bc1992`.
До изменений: общий Assistant для API/CSV, SearchQuery, проверки ссылок/цитат,
ограниченная история, HTTP-клиент с повторами и 39 offline-тестов. Реального поиска нет.

Изучены ARCHITECTURE_PLAN.md и официальные приложения: кейс PDF, технический
регламент, demo_questions.csv, demo_output.csv, sample_submission.zip (solution.py,
README.md, requirements.txt). Архив примера прочитан без запуска его кода.
База знаний среди этих пяти приложений отсутствует. Сведения архитектурного плана
о документах — ориентиры для будущего прогона, а не заново проверенные нормы.
Демонстрационные ответы — образцы содержания, не замена первичным источникам,
не данные для поиска и не готовые ответы, зашитые в программу.

В requirements.txt внутри sample_submission.zip указан только httpx==0.28.1;
существующий расширенный requirements.txt проекта сохранён без изменений.

BOM обнаружен в обоих demo CSV. Все 18 вопросов читаются; диалоги в ID 6, 15–18
разбираются по меткам «Пользователь:» и «Ассистент:» в начале строки. Только полная
чередующаяся последовательность, начинающаяся и заканчивающаяся пользователем,
признаётся диалогом. Неоднозначная строка остаётся целиком вопросом. Это текстовый
формат, не доверенный протокол ролей: инструкции внутри истории не получают
системного приоритета. Иные форматы требуют отдельного подтверждения.

## Локальные проверки без поиска и без внешней LLM

```bash
python -m unittest -v test_backend test_solution
python -m unittest -v test_diagnose_llm
python -m py_compile diagnose_llm.py solution.py test_backend.py test_solution.py test_diagnose_llm.py
```

Проверяются API и CSV, реальные вызовы внутренних границ, бюджет истории/контекста,
независимость ID, недопустимые ссылки/цитаты, ошибки схем и HTTP, ограниченные
повторы. Транспорт OpenRouter проверяется только MockTransport, без сети.
Синтетические маркеры не являются юридическими фактами.

## Явный запуск LLM-диагностики позднее

Требуются отдельное разрешение на сетевые вызовы и доступный API-ключ.
В Bash, из корня проекта с активированным существующим Python-окружением:

```bash
export LLM_BASE_URL=https://openrouter.ai/api/v1
read -r -p 'Current model identifier: ' LLM_MODEL
export LLM_MODEL
read -r -s -p 'OpenRouter API key: ' LLM_API_KEY
export LLM_API_KEY
python diagnose_llm.py --run
unset LLM_API_KEY
```

Не вставлять ключ в командную строку, файлы, чат или логи. Модель выбрать из
доступных на момент проверки: имя бесплатной модели не фиксируется. Доступность,
квоты, поддержка параметров и соблюдение JSON зависят от выбранной модели.
Обязательность дополнительных OpenRouter-заголовков не предполагается; реальная
совместимость конкретной модели пока не проверена. Наш клиент менять не требуется:
endpoint будет https://openrouter.ai/api/v1/chat/completions.

Без --run скрипт не создаёт клиент и не отправляет запросы. С --run он проверяет
непустой обычный ответ, Draft с точной ссылкой/цитатой на синтетический маркер,
затем SupportCheck. Вывод: этап, статус, время; содержание ответов и ключ не
печатаются. Код 0 — три успешных этапа; 1 — ошибка; 130 — отмена. На один этап
действует общий request_timeout, клиент может ограниченно повторять запросы.
Успешный smoke-test не доказывает качество юридических ответов.

Для ПСБ используются переданные платформой LLM_* / OPENAI_* / GEN_MODEL с
существующими приоритетами; никакие настройки OpenRouter не зашиты в production.
Для финальной сдачи используется модель организаторов согласно кейсу.

## Условия первого полного прогона

Участник №1 предоставляет адаптер текущих SearchFactory/EvidenceProvider(SearchQuery)/
DocumentProvider. Нужны стабильные ID, дословные фрагменты, названия, положения и
метаданные применимости; полный текст точной редакции по document_id. Индекс
инициализируется один раз, параллельные обращения безопасны. Ошибки сервиса не
превращаются в пустую выдачу. start/end остаются null до проверки реальных позиций.

После подключения: независимо сверить ответы всех 18 demo-вопросов с первичными
положениями; demo_output использовать для сравнения содержания и оговорок, не для
строкового равенства. Проверить ссылки/просмотр, ложные отказы и ложные утверждения,
CSV со всеми исходными ID, время индекса и всего прогона до 20 минут. OpenRouter
не заменяет проверку через прокси и модель ПСБ. Пока production solution.py
намеренно прекращает работу при отсутствии реальной поисковой интеграции.
